# 课程注册系统人员资料实现与测试报告

实现日期：2026-10-10；简化复测：2026-10-11。依据题目 PDF 第 9—12 页。

## 1. 功能与使用

教务员进入“人员资料”，选择学生或教师，按编号、账号或姓名查找，新增、编辑、确认删除或取消删除。

| 资料 | 字段 |
| --- | --- |
| 共用 | 系统编号、账号、姓名、出生日期、证件号、人员状态、密码和账号启用状态 |
| 学生 | 毕业日期 |
| 教师 | 院系 |

系统编号自动生成，账号创建后固定，编辑密码留空保留原密码。“毕业”等人员状态与账号是否启用分别保存。

已有库使用前执行 [add_person_profiles.sql](../database/add_person_profiles.sql)，新建库已包含人员表。脚本可重复执行，不清空已有数据；旧导入账号首次编辑时补全资料。日常数据库尚未由测试升级，认证升级前的登录会话需重新登录。

## 2. 保存与删除规则

- 检查字段、日期、唯一账号和证件号；保存失败整体回滚。版本检查防止旧页面覆盖新资料。
- 删除需要确认，可取消；确认绑定人员与版本，十分钟失效，取消或成功后不能重放。
- 无关联业务记录时删除人员及资料；已有选课、成绩或授课记录时保留人员，可停用账号。这是历史保护规则，原题未说明关联记录的删除方式。
- 停用、删除和重置密码后旧会话失效；修改姓名刷新显示。此入口只维护学生和教师。
