# 课程注册系统

软件工程课程设计项目，使用 PHP 和 MySQL 实现学生选课、教师授课和教务管理。使用原有 `Page` 网站和本机数据库；各账号通过浏览器访问同一份数据。

| 角色 | 主要功能 |
| --- | --- |
| 学生 | 查询课程，提交0–4个首选和0–2个备选，保存草稿，修改或删除课表，查看最终课表、账单及已完成学期成绩 |
| 教师 | 认领符合资格的教学班，查看本人课表和学生名单，在教学结束后录入、补录或更正成绩 |
| 教务员 | 维护学生和教师资料、任教资格及学期时间，随时关闭或开启选课，查看计费记录并重试 |

课程设计 PDF 的八个核心用例与异常分支见 [PDF 需求对照](PDF需求对照.md)，原网页操作步骤见 [项目使用说明](项目使用说明.md)。

新增的成绩多窗口冲突处理、验证结果及八个用例的后续边界检查见 [课程用例补充](tests/课程用例补充.md)。

## 启动原网站

需要 PHP 8.0+、PDO MySQL 扩展和 MySQL 8.0.16+。

1. 启动本机 MySQL，将 `config.example.php` 复制为 `config.local.php`，填写实际主机、端口、数据库名、用户及密码。
2. 新数据库先在 MySQL 客户端执行 [schema.sql](database/schema.sql)。脚本默认使用 `course_registration`，配置中的库名应与实际建表数据库一致。
3. 已有数据库运行下方升级命令。升级可重复执行，保留已有账号、课表、成绩与账单，补齐所需表、课程院系、计费重试时间和教学结束时间。每次拉取涉及数据库结构的更新后都应执行升级；Git拉取不会自动修改MySQL。
4. 在项目根目录启动 PHP，浏览器打开 <http://localhost:8000/login.php>。

```powershell
$phpExe = 'D:\phpstudy_pro\Extensions\php\php8.0.2nts\php.exe'

# 已有库升级；新库使用最新 schema.sql 后也可执行。
& $phpExe .\database\upgrade.php

& $phpExe -S localhost:8000 -t .\Page
```

PHP 路径按本机安装位置调整，关闭开发服务器按 `Ctrl+C`。使用 PHPStudy Apache 时，将网站根目录设为本项目的 `Page` 文件夹，然后使用 PHPStudy 中配置的域名和端口访问。课程答辩可在同一原站使用不同浏览器或普通窗口与隐私窗口分别登录不同角色。

仅空数据库需要样例数据时，可在启动网站前执行 `& $phpExe .\database\import_demo.php --demo`；已有数据时跳过。导入提供 `student01`、`teacher01`、`admin01` 等样例账号，实际登录密码与启用状态以原站初始化和现有数据库为准。

数据库配置优先使用已设置的整组 `CR_DB_*` 环境变量，否则读取 `config.local.php`。课程设计验收使用数据库模式；若此前设置过 `CR_DEMO_MODE=1`，启动前清除该变量。项目不自动读取 `.env`。本机配置位于网站目录外，已被 Git 忽略，不提交数据库密码或备份。

## 学期时间与成绩

教务员可在“关闭选课”页面随时申请关闭选课，无需等待截止时间；有有效学生登录会话时，系统弹出“有人正在选课”并拒绝关闭。学生退出登录即释放该浏览器会话，多浏览器登录分别计算；无活动会话按 PHP 的 session.gc_maxlifetime 过期（默认 24 分钟，至少 60 秒），学生页面请求和选课页面的名额刷新会续期。禁用账号或重置密码后的旧会话不再阻止关闭。

点击“重新开启选课”立即开放，默认持续 7 天，也可自定义未来截止时间。尚未到开始时间或已过截止时间时也能直接开启。学生和教师仍按开放状态及时间窗口进行选课、认领。此前已关课时，重新开启会恢复关闭前的教学班、志愿和占座，并撤销该次关闭结果与计费记录；已经录入或确认成绩的学期仍受成绩保护，不能撤销关课。所有时间均按北京时间处理，教学结束不能早于选课截止。

已关闭学期不能通过修改日期重新开放，但可以维护教学结束时间。选课关闭与教学结束是两个阶段：教师只有在选课已关闭且教学结束时间已到时，才可录入该学期本人教学班的成绩；学生只查看已完成学期的成绩。升级时缺失的教学结束时间按选课开始后五个月推定，教务员须根据实际教学安排核对并修正。

成绩录入支持多窗口冲突检查：旧页面保存、撤销、CSV 导入或确认成绩时，若相关成绩已经变化，本次操作会被拒绝并显示最新数据。单条保存只核对该学生，导入和确认核对全班；核对后可重新提交。CSV 检查基于导入页面打开时的成绩，不能识别打开页面之前已过期的离线 CSV，导入前仍应核对文件。

## 学费与自动重发

默认学费为最终有效课程数量 × 每门 300 元。停开课程和未补入的备选不收费。单价、课程明细、总额和请求编号随最终课表保存，重发沿用原账单。这里模拟计费系统接收，不产生真实扣款。

学生在“我的课表”查看账单；教务员在“任教与计费”查看状态、尝试次数及下次重试时间，也可手动“发送待处理记录 / 重试失败记录”。历史账单没有金额字段时保留原快照，不重新计算。

自动重发需要另一个终端持续运行后台任务，或由服务器计划任务定期调用一次任务：

```powershell
$phpExe = 'D:\phpstudy_pro\Extensions\php\php8.0.2nts\php.exe'
$env:CR_BILLING_RETRY_SECONDS = '60'
& $phpExe .\tools\billing_worker.php --watch

# 计划任务可使用以下单次入口，每次处理到期记录。
# & $phpExe .\tools\billing_worker.php --once
```

网站和后台任务应使用相同数据库与计费配置。默认 `CR_BILLING_MODE=success`；设置为 `fail` 可模拟接口不可用。若需要在任务运行中切换恢复，将两者的 `CR_BILLING_MODE_FILE` 指向网站目录外同一文本文件，内容写为 `fail` 或 `success`。失败记录按间隔重发，成功后停止；停止后台任务且未配置计划任务时，仅可手动重试。

可通过 `CR_BILLING_COURSE_FEE` 设置单价，最多两位小数；单价变更只影响之后生成的账单。PHPStudy Apache 采用环境变量时，修改后重启 Apache；CLI 任务也须读取相同配置。

## 课程设计实现范围

按题目 PDF 实现核心业务，用本地数据库或 JSON 只读快照模拟课程目录，用本地接收结果模拟财务系统。尚未接入真实 Ingres/DEC VAX 课程目录或真实财务接口，未实现 Windows 95/98 原生桌面客户端。

尚未验证中央数据库 2000 并发用户、本地服务器 500 并发用户、目录访问不超过 10 秒、80% 事务在 2 分钟内完成，以及每周全天可用且停机不超过 10% 的目标。事务和权限控制用于业务正确性，不等同于上述性能与可用性达标。具体差异见 [PDF 需求对照](PDF需求对照.md)。

## 演示规则与页面

首选最多4门、备选最多2门，均可留空。提交空方案会释放原首选名额；关课时备选按顺序递补到最多4门，无可用备选则保留实际数量。页面说明已缩短，账单课程明细、关闭结果和备选处理默认折叠。

出现“选课会话暂不可用”时先查看服务日志；若提示缺少`selection_sessions`，在项目根目录执行上方升级命令。升级后刷新并使用原库实际账号密码登录，不重新导入样例。
