# 关闭注册 S1—S7

最终同步版本：2026-10-14。

根据用户提供的照片核对。S7 条件部分被遮挡，预期结果“按设定时间间隔反复尝试发送，直到计费系统可用”可辨认。照片没有规定收费公式，本项目简化为最终课程数量 × 每门课程单价，默认每门 300 元。

| 场景 | 照片内容与预期 | 当前处理 |
| --- | --- | --- |
| S1 | 学生正在选课，管理员关闭注册；提示“注册正在进行中，无法关闭注册” | 有效学生会话存在时拒绝关闭并弹窗；退出或过期后可关闭，无需等待截止，多浏览器会话分别计算 |
| S2 | 教学班有 4 名学生、1 名教师；关闭后正常开课，出现在学生课表 | 保留教学班和有效选课，生成正常开课结果 |
| S3 | 首选不足最大数量，已有两个备选且至少一个符合开课条件；用备选补充课表 | 顺序尝试备选，检查容量、先修、时间冲突及重复课程；补位后再判断最低人数 |
| S4 | 教学班选课人数少于 3 人；取消该班，课表不再包含该班 | 首轮补位后仍不足 3 人则停开，取消有效占座并删除首选，尝试剩余备选 |
| S5 | 管理员关闭注册；计算学费并发送计费事务，返回账单和相应课表 | 事务内保存最终课程和金额快照，提交后模拟发送；学生课表显示账单，教务页显示明细和发送结果 |
| S6 | 教学班没有选课教师；取消该班，课表不再包含该班 | 即使已有 4 名学生仍停开；学生课表显示停开原因 |
| S7 | 计费系统不可用；按间隔反复发送直到可用 | 失败保存尝试次数、原因和下次发送时间；后台任务反复处理到期记录，可用后标记成功并停止重发 |

## 验证

使用浏览器按根目录[项目使用说明](../项目使用说明.md)第4节在原网站操作，观察课表、账单、失败次数和自动恢复。当前系统已完成独立数据库及HTTP检查，包括会话拦截、备选递补、停开和计费；后台进程在接收端失败时自动重试、恢复后成功并停止重复发送也已验证。39阶段、1067项完整回归全部通过，记录见`function_audit_regression.json`。

幂等升级入口为`database/upgrade.php`，保留原库账号、选课、成绩及账单；后台重发由`tools/billing_worker.php --watch`或计划任务`--once`执行。启动与配置见根目录[README](../README.md)。选课关闭与教学结束分开判断，成绩操作需等待教学结束。

首选可0–4门、备选可0–2门，无需填满；3+1可递补到4门，2+2可到4门，1+2及0+2保留实际较少数量，4+2无空位不递补。第一备选满员时可尝试第二备选。无成绩时可重新开启并恢复关闭前快照，有成绩时拒绝。
