# 课程注册系统关课修复与复测报告

修复日期：2026-10-10；代码简化复测：2026-10-11。当前总体结果见[测试报告](../课程注册系统测试报告.md)。

## 1. 修复结果

| 情况 | 修改后的行为 |
| --- | --- |
| 主动退课留下首选空缺 | 按备选顺序填入原空位 |
| 首备已有 2 人，补入后达到 3 人 | 正常开设 |
| 首备补入后仍不足 3 人 | 停开、恢复原备选顺序，继续尝试第二备选 |
| 原首选在补位后仍不足 3 人 | 停开，再用未尝试的备选补位 |

每次补位检查容量、先修课、重复课程和时间冲突。按方案最早保存时间、学生编号处理，每个备选最多尝试一次。已补入的班若停开，释放占座并更新尝试结果。

关闭在同一事务中完成，失败全部回滚，再次关闭不重复分配。

## 2. 课程设计写法

[admin_closure_db.php](../Page/admin_closure_db.php) 按“检查条件 → 读取数据 → 两轮取消与补位 → 保存结果”处理。原来的两段匿名函数改为普通循环，学生顺序由 SQL 排序，数组按编号修改，方便阅读和讲解。
